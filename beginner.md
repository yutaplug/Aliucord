# Aliucord Beginner Guide
## Installing Aliucord
Download [Aliucord Manager](https://github.com/Aliucord/Manager/releases/download/v1.3.0/aliucord-manager-v1.3.0.apk) APK and install it. Open it, grant all permissions, press **New install** and follow the steps.

## Installing plugins
1. In <#811275162715553823> or <#845784407846813696>, hold any message
2. Tap `View [Author]'s Plugins` (<#811275162715553823>) or `Install [Plugin name]` (<#845784407846813696>)
3. Install the plugin you want, then restart Aliucord (most plugins need it)
-# Search plugins with `/search plugin <name>` in <#811263527239024640>, or use the PluginWeb plugin for a built-in list

**Installing manually** (needed for #unmaintained-plugins, or if you already have the `.zip`)
1. Open the plugin's repo, switch to the `builds` branch and download `[PluginName].zip`
2. Move the `.zip` to the `Aliucord/plugins` folder with a file manager
3. Restart Aliucord

## Installing themes
1. Install [Themes](https://github.com/yutaplug/yutaplugins/raw/builds/Themes.zip) plugin by holding this message
2. In <#824357609778708580>, hold any message (**not the link**) and tap `Install [Theme name]`
3. Enable the theme in Themes plugin settings
-# Theme not working? Check the transparency mode, force stop app and clear cache or try the old Themer plugin instead.
